## Java-Version:
OracleOpenJDK 23.0.1

## Starten des Programms:
1. Es wird davon ausgegangen, dass das Projekt innerhalb der IDE "IntelliJ Idea" ausgeführt wird und Maven bereits installiert ist.
2. Mit Rechtsklick auf die "pom.xml" wird die Option ausgewählt, das Projekt als Maven-Projekt hinzuzufügen.
3. Im Dropdown Menü, im Maven-Fenster der IDE, unter "SmartHomeSzenarioEditor" das "Lifecycle" Menü öffnen.
4. Dort die Menüpunkte "clean" und "verify" auswählen und für diese den Maven Build durchführen.
5. Anschließend kann das Programm durch Ausführen der Startklasse ("src/main/java/main/SmartHomeApplication.java") gestartet werden.
6. Die Launcher.java in demselben Verzeichnis dient nur als Hilfsklasse für die Artefakterstellung.
